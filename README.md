# BankPulse – Banking Console Application

A simple Java-based banking application that allows users to create bank accounts, deposit money, withdraw money, and view account details through a console menu.

## Features

- Create new bank accounts
- Automatically generate unique account numbers
- Deposit money into an account
- Withdraw money from an account
- Prevent invalid deposits and withdrawals
- Search for accounts using account numbers
- Display all registered accounts
- Menu-driven console interface

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Java Collections Framework
- Scanner for user input

## How to Run

1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure Java JDK is configured.
4. Run `Main.java`.
5. Follow the console menu to perform banking operations.
